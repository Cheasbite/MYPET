# Welocome to MY Personal Expense Tracker
A Personal Expense Tracker writtern in python to track your daily spendings. <br>
It supports adding, deleting, summarizing and searching through your records. <br>

## Key Features:
- [x] Everything is locally stored and persist across multiple session
- [x] Use your Agent to help you understand your records that fit your needs when summarizing
    - Supported Providers:
        - [x] Ollama
        - [x] Gemini

> [!NOTE]
> The current supported providers are supported mainly because <br>
> testing them is possible.

This is a project for our course.

## Get Started:
Clone the repository
```sh
git clone https://github.com/Cheasbite/MYPET
cd MYPET
```

Run the code (Recommended)
```sh
python3 -m main
```
